DATA RIGHTS CENTER

Control your information.

Use this center to start a request concerning information associated with you. Available rights vary by jurisdiction and context.

Access

Request a copy or description of covered information.

Correction

Request correction of inaccurate covered information.

Delete

Request deletion where applicable.

Opt out / object

Submit an objection or opt-out request where applicable.

Never submit passwords, authentication codes, seed phrases, private keys or payment-card numbers through a data-rights request.
