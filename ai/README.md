# StellarNet AI Control Plane

The control plane is an application architecture for shared role-bound agents.

## Production stages
1. Identity
2. Least-privilege permissions
3. Tool registry
4. Scoped memory
5. Task queue
6. Human approval
7. Execution
8. Immutable-ish audit evidence
9. Billing/metering

## Safety
Agents do not receive implied legal authority, ownership, account access, payment authority, or registry authority. Those capabilities must be explicitly granted by the relevant application and user.

## Monetization
The control plane can support paid subscriptions, metered API usage, enterprise seats, namespace services, resolver services, implementation services, and marketplace commissions once corresponding payment products and backend enforcement are implemented and verified.
