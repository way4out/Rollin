# Rollin domain application map

This directory contains deployment-ready entry applications for the intended Rollin domain portfolio:
- .com — primary marketplace entry
- .ai — AI/data application entry
- .net — infrastructure/network application entry

These are app entry points, not proof of domain registration. Real .com/.ai/.net registration requires a registrar/account and payment or a verified promotion. The repository remains deployable on GitHub Pages while domain ownership is pending.
