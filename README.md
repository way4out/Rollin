# Rollin Commerce Hub

Rollin is a standalone, mobile-first commerce PWA built independently of Lovable hosting.

## Production surface
- GitHub Pages deployment via `.github/workflows/pages.yml`
- Responsive web/PWA experience for iPhone, Android and desktop
- Product discovery, search, categories, favorites, cart, demo checkout
- Rewards, membership, referral/share flows
- Merchant operating surface and lead capture
- Gaia human-first / sustainability design layer
- Offline-first service worker and installable manifest
- Verified-data gate for wallet/token features

## Monetization architecture
Designed for real revenue from:
1. Product sales / marketplace take rate
2. Merchant subscriptions
3. Memberships
4. Promoted discovery
5. Digital goods
6. Service integrations
7. Partner campaigns

Production payment collection is intentionally gated until real payment-provider credentials, merchant settlement rules, tax/shipping configuration and legal policies are supplied. The frontend does not fabricate transactions or earnings.
