Capacity model

Logical capacity is intentionally unbounded at the protocol level: hierarchical namespaces can add dimensions, paths, versions, and content-addressed identifiers without pre-materializing them.

This is a software namespace model, not a claim that StellarNet owns the global DNS root, an ICANN TLD, or every Internet registration.
