## Evidence boundaries
- GitHub history proves source history, not runtime success.
- Render deployment status proves deployment state, not feature correctness.
- Onchain state requires a transaction receipt plus contract/token address.
- Marketplace settlement requires verified payment plus order state.
- AetherOS hardware success requires actual DSi/NDS runtime verification.
