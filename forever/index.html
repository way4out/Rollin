FOREVER COMMONS

A free-to-use naming layer for anyone: human-readable OEQL names, deterministic identity, and an HTTPS compatibility path — without pretending that a name is legally registered when it is not.

Create a free OEQL name

Enter a name. The browser derives a deterministic free identifier locally. No payment and no account are required for this demo/protocol layer.

Free by design

The protocol format is free to use. It can be implemented by anyone and does not require a paid domain purchase merely to create a deterministic identity.

Open resolution

oeql://name.forever is an application/deep-link form. The HTTPS fallback keeps the experience usable in ordinary browsers.

Portable identity

Names are normalized and hashed in the browser, so the same input produces the same protocol identifier without a central account.

No false ownership

A generated protocol name is not automatically a legal domain registration, trademark right, or exclusive claim in a third-party registry.

Resolution model

1 · Normalize2 · Derive ID3 · Resolve4 · Publish5 · Verify

A compatible client may resolve an OEQL identifier directly. Otherwise, the HTTPS compatibility route can serve the application. Registered namespaces can be layered on later without changing the protocol shape.

What “free forever” means here

Free protocol use: yes — the naming algorithm and client-side format can be offered without a fee.

Guaranteed free global registration forever: not claimed — that depends on whoever operates a particular registry, namespace, hosting service, or blockchain.

The goal is an open standard where people can create and use names without a mandatory payment gate, while registered names remain governed by the actual registry that controls them.
